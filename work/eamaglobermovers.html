Project 01 — live system

Inbox → WhatsApp:
zero missed moves.

n8nGmail APIWhatsApp APIRole: design + build + deploy

EammaGloberMovers was manually triaging a shared inbox — costing 10+ hrs/week and losing quotes to slow replies. I built an automated pipeline using n8n plus email-to-WhatsApp alerting that pushes every move request to the dispatcher in minutes.

  n8n canvas export — live flow
GMAIL TRIGGER → PARSE → DEDUPE → WHATSAPP.SEND → LOG

Problem → Process → Solution → Result

PROBLEM

Move requests arrived by email at all hours. Staff polled the inbox between jobs; peak days buried urgent requests. Every missed or late reply was a lost move.

PROCESS

Shadowed the inbox for one week, catalogued request shapes, then built the flow in n8n (self-hosted): Gmail trigger → structured parse (date, pickup, destination, phone) → dedupe on message-id → formatted WhatsApp alert with one-tap reply draft → append to log sheet. Added retry-with-backoff and a dead-letter error channel that pings me.

SOLUTION

One flow, five nodes, fully documented runbook. Dispatcher gets: customer name, move date, route, phone, and the original email link — within ~2 minutes of arrival, 24/7.

RESULT → Response time from hours to minutes. 0 missed alerts since launch — roughly 8–10 hrs/week of triage handed to the pipeline.
