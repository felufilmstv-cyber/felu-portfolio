Project 03 — reporting pipeline

6 hrs/week,
now a 20-min review.

n8nLLM summariserSheets APIRole: design + build

Weekly ops reporting was hand-assembled every Friday from three sources. I replaced it with a scheduled pipeline: pull → normalise → validate → LLM summary with quoted figures → delivered Monday 07:00.

  monday report — live output
MON 07:00 · DELIVERED · ✓ SCHEMA VALIDATED

PROBLEM

6 hours of copy-paste across Sheets, inbox and CRM every week. Errors crept in; nobody trusted the deck.

PROCESS

Built source connectors with schema validation that blocks the send on mismatch (fail loud, never silently wrong). The LLM writes only the narrative layer, with every figure cited to its cell — no invented numbers. Full run log, timestamped archive.

RESULT → Manual work 6h → ~20 min review (−94%). One timestamped source of truth the team actually trusts.
