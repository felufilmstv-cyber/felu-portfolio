PROJECT 01 — LIVE SYSTEM

Emma Glober Movers: leads → WhatsApp

Job leads from three inboxes routed straight to the team's WhatsApp group in real time — no manual checking or forwarding.

● live systemn8nOutlook (Graph API)Wassenger APICustom JS

Problem

Leads arrived via direct enquiries, Hipages and Findamover across separate Outlook inboxes. The owner hand-checked each one and forwarded winners to WhatsApp — delays and missed leads whenever he was busy, on jobs where speed to first contact decides who wins the booking.

Solution

A scheduled n8n workflow that polls all three inboxes in parallel, filters for genuine enquiries, reformats each one into a clean WhatsApp-ready message with custom JavaScript, and sends it to the team group via the Wassenger API — no human step in between.

RESULT → Owner removed as the manual bottleneck. Instant team alerts, faster first contact — zero extra admin.

PROJECT 03 — LIVE PIPELINE

Reel Scheduler: Sheets queue → Instagram + Facebook

An automated content pipeline for a social media agency that schedules, captions, and publishes Reels to Instagram and Facebook directly from a Google Sheets queue — no manual posting required.

● live pipelinen8nGoogle SheetsGemini APIMeta Graph APICloudinaryPrivate client project

Problem

The agency managed Reel publishing for multiple client accounts manually — writing captions, tracking scheduled times across a spreadsheet, and logging into Instagram and Facebook separately to post each video at the right moment. It didn't scale past a handful of clients, and consistent posting schedules were hard to maintain.

Solution

Built an automated pipeline that runs every five minutes, checking a Google Sheets content queue for the next Reel due. For each due item it pulls the video URL and details, generates platform-specific captions with Google Gemini, publishes to Instagram via the Meta Graph API (confirming processing status first), publishes the same Reel to Facebook Reels, then marks the spreadsheet row posted — the whole calendar runs from one sheet.

RESULT → Manual posting and caption-writing gone entirely — a consistent scheduled Reel calendar across multiple client accounts, zero added headcount.
